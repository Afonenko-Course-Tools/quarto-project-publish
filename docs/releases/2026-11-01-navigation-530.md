# Publisher 5.3.0: общее меню курса

Источник поведения — PR18 `ebd0413654ed167bbeeff00cf45986c292edc06c`
поверх опубликованного 5.2.0. При `course-navigation.enabled: true`
Publisher вызывает публичный `course-navigation/public.ts` →
`composeNavigation` из того же installation namespace. Состав меню берётся
из корня и web-компонентов `subprojects`; PDF-only части не требуют HTML
входа. Отдельная модель курса или второй список ссылок не создаются.

Navigation владеет отрисовкой HTML/Reveal и относительными ссылками.
Publisher вызывает его после QRC и до Core post-hook и конечного ZIP;
privacy/currentness и отдельные genuine owner operations сохраняются.
Без явного включения и в самостоятельном компоненте остаётся прежний
маршрут. Общую тему и системные шрифты поставляет `course-theme-html` 1.0.0
в согласованном Course9.1.0.

Минимальная версия Quarto — 1.11.5; workflow проверяет 1.11.5 и 1.11.6
на отдельных hosted runners. Фактический успех матрицы и публикация
должны быть подтверждены на окончательном commit перед tag/release.
Ссылка на source candidate не означает наличие опубликованного тега.
Согласованный source candidate Course — `aadeea62b54d4b129d98215241737c35d2f17851`
(tree `c88fcd3468e10d848ffe10ffd21cc638e5f032c8`); Navigation/Core/Presentation9.1.0,
Theme1.0.0. Это точная Git-привязка замороженного авторского кандидата,
а не заявление независимой приёмки или опубликованного тега. Остальные
companions закреплены на опубликованных QRC3.2.0
`798f8c0d9f87fd5dcfe9ee85b79df57e647d2f3c`, Download3.3.0
`2794813728039893ed48b1f1007be71e48d5a6bc` и public validator C9.0.0
`eb35a5f16600915bdc78a41c21601e1ae92fe019`; C CLI не вызывается.

Локально установленный тест прошёл на Quarto 1.11.5 и 1.11.6 с указанным
Course source candidate: student/full/student, HTML/Reveal, вложенные страницы,
PDF-компонент, standalone, отсутствие общей композиции без opt-in и браузерные поиск, активный
раздел, Bootstrap на ширине320px, URL-префикс и отсутствие Google Fonts.
Отдельный native default-тест на 1.11.6 прошёл: genuine root/child operations,
конечные mounted URL, единственный ZIP с exact Download bytes и отказ без
Core proof с сохранением прежнего ZIP. Эти результаты не заменяют final
hosted CI и независимую приёмку. Проверки полноценного курса, all135 и C
exports в эту подготовку не входят.
Отдельный наблюдаемый отказ SP `OPERATION_CHANGED` не исправляется в5.3.0;
его диагностика сохранена вне release source и последующая правка должна
опираться на опубликованные Core9.1.0/Publisher5.3.0.
