# Publisher 5.2.0

Новая версия сохраняет отдельно проверенные исходники компонента. Родительский commit: `4a772e0415d165cd8c85ba2fa490b4a38e9777f0`. Независимая техническая приёмка исходников: `b3-owner-release-root-acceptance-20261031.json` в журнале исполнения Java/SP.

В этой дельте меняется только номер версии в дескрипторах расширений; остальные исполняемые файлы, схемы, API и тесты совпадают с проверенным родителем. Существующие опубликованные теги не заменяются.

Новый тег и выпуск создаются после независимой проверки этой дельты и необходимых CI. Приёмка компонента не означает завершение проверки всех 135 заданий курсов, новых образов и восстановления данных.
