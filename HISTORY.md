# 4.0.0

Корневой subprojects заменяет прежнюю конфигурацию частей. Адреса повторяют нормализованные пути папок; форматы документов выбираются через native Quarto inspect с профилями и front matter. Сохранены нативные книги, смешанные HTML/Revealjs сайты и отдельный маршрут невеб-результатов. Независимые native проекты не объединяют области ID в общий экспортный банк. Добавлена демонстрация examples/course и проверки единственного рендера выбранных документов.

Собственные defaults и группы профилей частей сохраняются в проверке audience,
текущих коллекциях и ожиданиях Core. Выбранные исходные файлы проверяются на
containment и symlink перед документным inspect и рендером частей.

# Происхождение репозитория

Координатор публикации выделен из `AfonenkoA/quarto-reference-catalog`, исходный коммит `80c29236416c9f28eebd9404497d6978f02e7f9d`. История исходного репозитория сохранена в предках первого коммита выделения. С версии 3.0 payload заменён на `course-site`: обычные native hooks Quarto, текущие outputs и установленный Core/QRC. Прежние Publisher lifecycle, snapshots, rollback и custom preview удалены; GitHub repository сохраняет прежнее имя.
